AI‑Lawyer Prototype – Solution Overview (2‑page Summary)

Project: Haqdaar – AI Lawyer
Assignment: Kuku FM AI Generalist – Problem 2

1. Goal & Core Requirements

  • Conversational AI (text & voice) for everyday legal problems in India.
  • Public prototype URL – no login or personal API key required.
  • Model‑swap friendly – model chosen only via .env variables.
  • Re‑runnable test: .\node.cmd run_tests.mjs produces raw outputs.
  • Raw outputs for 14 test cases stored in raw_outputs/.
  • Free‑tier services only; no paid APIs.
  • Honesty: AI only cites laws using [[ID]] tokens from a built‑in library.
  • Explicit safety alerts when user mentions arrests, court, etc.

2. Architecture Snapshot

All JavaScript runs on plain Node 18+, no external npm packages.

3. Model Swap Point

All model info lives in .env:

LLM_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai   # or any OpenAI‑compatible endpoint
LLM_API_KEY=YOUR_KEY
LLM_MODEL=gpt-oss-120b               # current free model (or gemini‑3.8‑flash, etc.)
LLM_MODEL_FAST=gpt-oss-120b-fast      # optional – used for Practice mode

Changing a model requires only editing .env and restarting the dev server.

4. Running & Testing

  1. Configure .env (API key + valid free model ID).
  2. Start locally – npm run dev (or .\node.cmd dev-server.mjs).
  3. Run full suite – .\node.cmd run_tests.mjs.
    • Generates raw_outputs/<case>.txt (exact LLM responses) and summary.md.
    • Ensures reproducibility: a reviewer can run the same command on a fresh clone.
  4. (Optional) Deploy – push to GitHub, create a Vercel project, add the same env vars, and deploy. HTTPS enables the Web Speech API.

5. Honesty & Anti‑Hallucination Design

  • LIB: 42 verified law entries.
  • AI may cite only via [[ID]]; core.js expands these tokens.
  • validate() flags unknown sections, case names, AIR/SCC citations, raw statutes, and missing [[ID]].
  • If validation fails or /api/chat is unreachable, UI falls back to “AI unavailable – basic guide”.
  • Escalation regex (clientEscalation(), CRISIS) shows a safety card recommending a real lawyer.
